## Architecture / retrieval flow

- Ingest → chunk → embed → index into a vector store (Qdrant or Chroma, selected via `VECTOR_STORE` in `.env`)
- Query → retrieve top-k context → build prompt → call LLM (Claude or OpenAI, selected per-call) → return answer + sources
- See `src/rag/` for the pipeline, `src/interface/` for the two interchangeable interfaces (FastAPI API and Streamlit UI, selected via `INTERFACE` in `.env`)

## Ingestion pipeline

Automated via `ingestion/ingest.py`:

```bash
uv run python -m ingestion.ingest --source <path-or-uri>
```

## Monitoring

User feedback (👍/👎 per answer) is captured to Postgres (`monitoring/feedback.py`) and visualized in Grafana, provisioned automatically from `monitoring/grafana/`. TODO — add ≥5 dashboard panels and a screenshot once the dataset is live.

## How to run

1. Copy `.env.example` to `.env` and fill in API keys.
2. Pick an interface and vector store profile, then bring the stack up, e.g.:
   ```bash
   docker compose --profile fastapi --profile qdrant up --build
   ```
   (swap `fastapi`→`streamlit` and/or `qdrant`→`chroma` as needed)
3. Ingest data: `docker compose --profile ingest run --rm ingest`
4. FastAPI: http://localhost:8000/docs · Streamlit: http://localhost:8501 · Grafana: http://localhost:3000

### Local development (without Docker)

```bash
uv sync --extra fastapi --extra streamlit --extra qdrant --extra chroma --extra eval --extra dev
uv run uvicorn src.interface.api:app --reload
```
